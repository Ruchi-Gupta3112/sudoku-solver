# Sudoku Studio

A responsive Sudoku game and solver built with plain HTML, CSS, and JavaScript.

## Run

Open `index.html` in a modern browser. No installation or server is needed.

## Use

- Choose a difficulty and select **New puzzle** for a fresh board with one solution.
- Type 1–9 into empty squares. Arrow keys move between squares; Backspace or Delete erases an entry.
- Red squares identify repeated numbers in a row, column, or 3×3 box.
- Select **Solve puzzle** to complete the current board using recursive backtracking.
- Select **Reset entries** to return to the starting puzzle.
- Select **Blank board** to enter a puzzle of your own, then solve it.
